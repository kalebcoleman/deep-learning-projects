# Archive

This folder preserves legacy or non-primary material without keeping it in the active notebook-first workflow.

- `empty-placeholders/`: zero-byte or placeholder `src/`, `scripts/`, and notebook files.
- `legacy-code/`: older helper code and script entrypoints that are not the main path for coursework review.
- `legacy-root/`: old root-level scaffolding and notebook checkpoint copies.
- `runtime-state/`: generated outputs, temporary files, tool state, caches, and logs.

Nothing here is required for the main notebooks listed in `docs/notebook-index.md`.
