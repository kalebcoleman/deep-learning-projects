# Project 01: ANN Baseline

Feedforward neural network baseline for a supervised learning task.

## Contents
- `src/`: model, loss, data loading, and training loop.
- `notebooks/`: exploratory experiments and analysis.
- `scripts/`: entrypoint for running training.

## Run
From this folder:
```
bash scripts/run.sh
```

## Outputs
Artifacts (models, logs, results) are ignored via the top-level `.gitignore`.
