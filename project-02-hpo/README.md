# Project 02: Hyperparameter Optimization

Search over model/training hyperparameters and compare results.

## Contents
- `src/`: model factory, search logic, training, and metrics.
- `notebooks/`: analysis of HPO results.
- `scripts/`: run grid or sweep experiments.

## Run
From this folder:
```
bash scripts/run_grid_search.sh
```

## Outputs
Search results and checkpoints are ignored via the top-level `.gitignore`.
