# Project 03: CNNs and Visualization

Convolutional neural network training plus filter visualization.

## Contents
- `src/`: data loading, CNN model, training, and visualization utilities.
- `notebooks/`: CNN visualization notebook.
- `scripts/`: primary training run command.

## Run
From this folder:
```
bash scripts/run.sh
```

## Outputs
Generated figures and checkpoints are ignored via the top-level `.gitignore`.
