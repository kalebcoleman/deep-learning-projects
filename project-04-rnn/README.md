# Project 04: RNN Sequence Modeling

Sequence modeling with recurrent neural networks.

## Contents
- `src/`: dataset, tokenizer, RNN model, and training loop.
- `notebooks/`: sequence analysis notebook.
- `scripts/`: primary training run command.

## Run
From this folder:
```
bash scripts/run.sh
```

## Outputs
Generated results and checkpoints are ignored via the top-level `.gitignore`.
