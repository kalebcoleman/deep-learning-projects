# Project 03: Fashion-MNIST CNN

Notebook-first CNN project for Fashion-MNIST classification and model comparison.

## Contents

- `notebooks/03_fashion-mnist-cnn.ipynb`: main project notebook.
- `Project_3.pdf`: original assignment handout.
- `data/`: Fashion-MNIST CSV files used by the notebook.

## Run Notebook

```bash
jupyter lab notebooks/03_fashion-mnist-cnn.ipynb
```

The old empty `src/`, `scripts/`, and placeholder visualization notebook were moved to `archive/empty-placeholders/`. Generated outputs and temporary files were moved to `archive/runtime-state/`.
