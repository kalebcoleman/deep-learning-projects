# Project 04: Wildfire Smoke Detection

Notebook-first computer-vision project for wildfire smoke bounding-box prediction.

## Contents

- `notebooks/04_wildfire-smoke-bbox.ipynb`: main project notebook.
- `Project_4.pdf`: original assignment handout.
- `data/`: wildfire smoke image dataset and annotations.

## Run Notebook

```bash
jupyter lab notebooks/04_wildfire-smoke-bbox.ipynb
```

The previous RNN-labeled folder name and empty script placeholders were retired because the working notebook is a wildfire-smoke CNN bounding-box project. Those placeholders are preserved in `archive/empty-placeholders/`, and generated outputs were moved to `archive/runtime-state/`.
